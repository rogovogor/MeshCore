# Синхронизация времени и улучшения страницы CLOCK для eInk companion

## Область применения

Изменения применяются к companion-сборкам, использующим `examples/companion_radio/ui-new`
с eInk-дисплеем — именно там включена отдельная страница CLOCK.

Затронутые варианты:

- `heltec_e213`
- `heltec_e290`
- `thinknode_m1`
- `thinknode_m5`
- `wio-tracker-l1-eink`

## Что изменено

### 1. Синхронизация времени через advert-таймстемпы для companion

Добавлена та же кворумная синхронизация через advert-таймстемпы (как у ретранслятора) в `examples/companion_radio/MyMesh.*`.

Поведение:

- Накопление верифицированных advert-таймстемпов в кольцевой буфер.
- Режим быстрого bootstrap:
  - кворум `3/5` когда часы ещё ненадёжны
- Режим коррекции дрейфа:
  - кворум `7/10` когда часы уже доверенные или ранее синхронизировались
- Отклонение заведомо неверных таймстемпов вне диапазона:
  - `2020-01-01 UTC`
  - `2050-01-01 UTC`
- Применение коррекции только при значимом расхождении.

Источники времени по приоритету:

- аппаратный RTC → `RTC`
- bootstrap из контактов → `CNT`
- время установленное приложением → `APP`
- кворумная синхронизация через advert → `ADV`
- если GPS валиден на момент кворума — GPS остаётся авторитетным, источник → `GPS`

Чтобы mesh не сбивал свежеустановленное приложением время, синхронизация через advert
блокируется на 6 часов после `CMD_SET_DEVICE_TIME`.

### 2. Метка источника времени на странице CLOCK

Страница CLOCK на eInk теперь отображает компактную метку источника времени внизу:

- `RTC`
- `CNT`
- `APP`
- `ADV`
- `GPS`

Когда текущий источник — advert-синхронизация, дополнительно показывается последняя примененная коррекция.

### 3. Фикс PM-only оверлея страницы CLOCK

Исправлена утечка «режима тишины» страницы CLOCK для публичных/канальных сообщений.

Предыдущее поведение:

- PM и канальные сообщения хранились в одной очереди непрочитанных.
- Оверлей PM страницы CLOCK брал верхнюю запись без проверки типа.
- Если сначала пришёл PM, а затем канальное сообщение — страница CLOCK могла показать канальное поверх часов.

Новое поведение:

- Записи непрочитанных хранят флаг `is_pm`.
- Оверлей страницы CLOCK смотрит и потребляет только последний PM.
- Канальные/публичные сообщения по-прежнему ставятся в очередь для экрана предпросмотра сообщений.
- Канальные/публичные сообщения больше не пробиваются через оверлей страницы CLOCK.
